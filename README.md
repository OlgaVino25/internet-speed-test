# Internet Speed Tester

CLI-утилита на Python для замера скорости интернета. Скачивает указанный
ресурс N раз последовательно, считает среднее время запроса, суммарный
объём данных и печатает среднюю скорость в мегабайтах в секунду.

По умолчанию качает тестовый файл на 10 МБ с Cloudflare, но можно указать
любой URL — например, тяжёлую картинку или архив.

## Требования

- Python 3.10 или новее
- [uv](https://docs.astral.sh/uv/) для управления зависимостями
- Доступ в интернет

## Установка

Клонируй репозиторий и синхронизируй окружение:

```bash
git clone https://github.com/OlgaVino25/internet-speed-test.git
cd internet-speed-test
uv sync
```

**Как проверить.** Команда `uv sync` создаст виртуальное окружение `.venv/`,
скачает `requests` и поставит сам пакет в editable-режиме. В конце вывода
не должно быть ошибок.

## Запуск

Замер по умолчанию — 10 запросов к файлу на 10 МБ:

```bash
uv run speedtest
```

Свой URL и количество запросов:

```bash
uv run speedtest https://example.com/big.jpg -n 20
```

Без прогревочного запроса (тогда первый замер будет включать DNS и TLS):

```bash
uv run speedtest --no-warmup
```

### Флаги

| Флаг | Описание | По умолчанию |
| --- | --- | --- |
| `url` | Адрес ресурса для скачивания | тестовый файл Cloudflare на 10 МБ |
| `-n`, `--runs` | Количество последовательных запросов | `10` |
| `-t`, `--timeout` | Таймаут одного запроса в секундах | `30` |
| `--no-warmup` | Отключить прогревочный запрос | выключено |
| `-v`, `--verbose` | Подробный вывод уровня DEBUG | выключено |

## Тесты

Запустить все тесты:

```bash
uv run pytest
```

**Как проверить.** Все 18 тестов должны пройти за десятые доли секунды.
Тесты не обращаются к сети: `requests.Session` заменён моком через
`unittest.mock`, поэтому можно запускать их в CI без интернета.

## Запуск в Docker

Собрать образ:

```bash
docker build -t internet-speed-test .
```

Запустить замер с параметрами по умолчанию:

```bash
docker run --rm internet-speed-test
```

Свой URL и количество запросов:

```bash
docker run --rm internet-speed-test https://example.com/big.jpg -n 20
```

Либо через `docker compose`:

```bash
docker compose up --build
```

## Как считается скорость

Для каждого отдельного замера:

```text
speed_mb_s = (bytes_downloaded / 1024 / 1024) / seconds
```

Итоговая средняя скорость — это **суммарный объём, делённый на суммарное
время**, а не среднее арифметическое скоростей. Так корректнее: если один
запрос вернул больше данных, чем другой, его вклад в общую цифру должен
быть пропорционально больше.
